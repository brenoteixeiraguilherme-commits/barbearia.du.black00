horário

Escolha o serviço, a data e um horário sugerido. Por enquanto, este site está em modo demonstração: não há banco de dados conectado, então o horário ainda não fica reservado e não podemos garantir disponibilidade.

Modo demonstração
Para evitar reservas duplicadas, confirme seu horário diretamente com a barbearia pelo WhatsApp. O sistema online só deve ser ativado após configurar banco de dados e validação de disponibilidade no servidor.

Ao continuar, você enviará os dados preenchidos em uma mensagem para a barbearia. Nenhuma reserva é gravada neste site.
